# Security policy

Security fixes are provided for the latest version on the `main` branch.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/ariel-ps/herdr-alerts/security/advisories/new).
Include affected versions, reproduction steps, and impact. Do not include
credentials, private sound files, or other sensitive data.

If private reporting is unavailable, open a repository issue requesting a
private contact method without disclosing vulnerability details.
